Beginner

What fits in the window?

A tokenizer maps text into integer IDs drawn from a fixed vocabulary, and the model receives a bounded sequence of those IDs. The limit covers the entire request state—instructions, prior turns, retrieved documents, tool output, multimodal tokens where applicable, and reserved generation space. The context window is therefore an addressable working set, not durable memory, and nominal capacity says nothing by itself about recall fidelity across position.

Tokenization changes the real cost. Code, tables, uncommon names, multilingual text, and serialized tool output can expand differently under the same tokenizer, so character or word counts are only rough proxies.

The window has competing allocations. Preserving every historical turn may reduce room for primary evidence or output; dropping too much can sever constraints and references that later turns depend on.

Visibility is not retrieval. A fact can be inside the window and still fail to influence the answer because attention, position, distractors, or instruction conflict suppress its effective contribution.

Intermediate

How should the window be assembled?

Context engineering is an allocation and ranking system. Sparse and dense retrieval generate candidates with different failure profiles; metadata constrains scope; rerankers model query-document interaction; summaries compress old state; pinned instructions establish precedence. The assembled prompt needs explicit provenance, deterministic ordering, conflict handling, and a budget that reserves capacity for generation rather than treating the model limit as free storage.

Wusable = Wmodel − (system + conversation + retrieval + tools + output reserve)

Chunking sets the retrieval unit. Fixed windows are easy to index but can split arguments; semantic or structural chunks preserve discourse but vary in size. Parent-child retrieval can search small units and return their larger source context.

Position is an experimental variable. Evaluation should permute evidence across beginning, middle, and end; add plausible distractors; separate dependent facts; and test whether conflicting late instructions override earlier authoritative material.

Compression changes the evidence. Extractive compression preserves wording but may lose relationships. Abstractive summaries preserve a narrative at the risk of hallucination, flattened uncertainty, and irreversible omission.

Retrieval metrics and answer metrics diverge. Recall@k can succeed while the generator ignores the evidence; a fluent answer can score well while citing the wrong span. The evaluation stack has to separate candidate recall, ranking, utilization, and faithfulness.

Advanced

What makes long context expensive and difficult?

Transformer attention projects hidden states into queries, keys, and values, then materializes or tiles an interaction over sequence positions. Standard dense attention has O(n²) score interactions; FlashAttention reduces memory traffic and intermediate storage without changing that asymptotic relationship. Autoregressive decoding avoids recomputing prior keys and values by retaining a KV cache whose footprint grows linearly with sequence length, layer count, KV heads, head dimension, batch size, and bytes per element.

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

Position extension is not free capacity. RoPE scaling, interpolation, and altered frequency schedules can extend addressable positions, but phase resolution, training distribution, and attention behavior still determine whether distant dependencies remain usable.

KV cache design controls deployment. Multi-query and grouped-query attention reduce KV heads; lower-precision caches reduce bytes; paging reduces fragmentation; prefix caching amortizes repeated prompts; eviction policies decide which earlier states survive pressure.

Architectures encode different locality assumptions. Sliding-window and block-sparse attention restrict connectivity, recurrent memory compresses past state, and state-space or hybrid systems trade direct pairwise access for more scalable sequence propagation.

Effective context is measured behavior. A useful evaluation crosses sequence length with task type, evidence position, distractor density, dependency distance, output length, and latency instead of reporting one maximum-token number.

4o, other models, and the math underneath

Context length was only one axis.

Model research also meant comparing how different systems behaved inside the same kind of work. GPT-4o mattered as a benchmark for conversational attunement, warmth, multimodal fluency, and creative language. Other models could be compared for instruction fidelity, coding strength, latency, local deployment, cost, and how reliably they held onto details across a long exchange.

VECTORS / MATRICES

Representation is basis-dependent

Token and residual-stream states are vectors, while learned matrices rotate, scale, mix, and project them into attention and MLP subspaces. Individual coordinates are rarely interpretable in isolation; information is distributed across directions and transformed repeatedly through residual updates.

DOT / COSINE

Similarity depends on geometry

A dot product mixes angular alignment with magnitude. Cosine similarity normalizes both vectors and measures direction only. Retrieval behavior therefore changes with normalization, embedding anisotropy, corpus density, and whether the model was trained for symmetric similarity or query-document asymmetry.

SOFTMAX / LOGITS

Temperature reshapes competition

Softmax exponentiates relative logits into normalized weights. Dividing by temperature sharpens or flattens the distribution; subtracting a constant changes nothing. In attention it mixes value vectors, while in decoding it defines a distribution later modified by sampling rules.

LOSS / OPTIMIZATION

The objective is not the whole behavior

Next-token cross-entropy trains probability mass toward observed continuations, but instruction following and preference behavior are subsequently shaped by post-training data and objectives. Calibration, reward-model error, and distribution shift separate training loss from lived model quality.

QUANT / LOCAL

Approximation is structured

Quantization maps weight blocks into lower-precision representations with scales and, depending on the scheme, zero points or codebooks. Group size, outlier handling, activation precision, and KV-cache format determine whether memory savings preserve the behaviors being evaluated.

EVAL / HUMAN

4o exposed a missing axis

Task scores do not capture whether a model preserves tone, subtext, exact phrasing, creative continuity, correction history, and relational context across a long exchange. GPT-4o served as a benchmark for those coupled qualities; comparison with other models made their absence measurable through repeated use.

More context is useful when the model can still find the signal.

The practical lesson was to treat long context as a full-stack problem: model architecture, inference memory, retrieval, prompt assembly, evaluation, and human judgment all meet inside the same window.
