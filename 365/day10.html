NERV TERMINAL MONITOR — LOCAL VISUAL SIMULATION

Data Boundary

Local visual model: Every metric is generated in this document from time, fixed page metadata, and bounded visual variation.

No machine inspection: The page does not read system files, logs, hardware state, nearby devices, or network information.

No transport: The interface makes no data requests. Its only links are fixed same-origin routes inside the 365 collection.

Visual Encoding

  • Hexagonal Load Grid: Local oscillator values move the cells between calm, active, and alert states.
  • 7-Segment Displays: Constructed from Unicode block characters (█▀▄▌▐) to simulate vacuum fluorescent displays. All numeric readouts use this style.
  • Seismic Waveforms: Canvas-rendered local curves visualize archive-bus and render-queue activity.
  • Hex Ring Chronograph: 60-position hexagonal ring with rotating solid hex (◉) marking seconds for HQ Time.
  • Terminal Widget: A local event model reports page-field and render states without reading system logs.

Color System (Phosphor CRT)

  • Phosphor-Green (#00ff41): Normal operations, safe states, active sync
  • Phosphor-Orange (#ff6b00): Warnings, moderate load, attention required
  • Red (#ff0040): Critical thermal, memory pressure >90%, system alerts
  • Sage (#8fb3a5): Minimal text labels, metric annotations
  • Burgundy (#0f0505): Cathode-void background

MAGI Column Layout

  • MELCHIOR-1 (硬件): Hardware/Soul — simulated load cells, thermal model, and LCL memory pressure.
  • BALTHASAR-2 (網路): Archive/Soul — local page-bus waveform, render queue, and fixed 365 manifest.
  • CASPAR-3 (安全): Security/Soul — local event model, connection matrix, status hexes, and page-view uptime.

Technical Implementation

Local visual state updates at a modest interval and stops animating when reduced motion is requested.

The waveform history is held in memory for this page view only.

No API endpoints, device permissions, persistent storage, or caller-selected destinations are used.

Every panel source label identifies its local simulation role.

Cross-Platform Boundary

The same fixed local simulation runs in any modern browser. Host operating-system details are neither needed nor inspected.
