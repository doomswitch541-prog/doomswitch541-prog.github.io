Persistent Memory

SolarFlare remembers facts about you across sessions. Toggle individual memories on/off, define trigger keywords, and control exactly what context gets injected.

⚡

Real-Time Streaming

Watch responses generate word-by-word with live token counting, speed metrics, and detailed timing breakdowns in the debug panel.

🔒

Complete Privacy

Everything runs locally on your machine. No external API calls, no cloud processing, no data leaves your computer. Ever.

🔍

Neural Trace Debug

2000+ entry debug panel with live flash animations, millisecond timestamps, and verbose logging of every request, response, and memory injection.

📊

Context Tracking

Visual context window usage with token breakdowns for system prompts, memory context, and conversation history.

🔑

Keyword Triggers

Define your own memory trigger phrases. When you say "I prefer" or "I like", SolarFlare automatically captures and stores that context.
