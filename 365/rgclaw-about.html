RGClaw

Give a local model a task, a small set of tools, and room to work. RGClaw turns the result into a visible execution: every thought, tool call, return value, and final answer arrives step by step.

The execution loop

A task becomes a sequence you can inspect.

Define

Name the agent, choose the local model, write its operating instructions, and select only the tools it needs.

Run

Give it a concrete task. The runner sends the task and tool definitions to Ollama on the same machine.

Observe

Reasoning steps and tool calls stream into the browser over WebSocket as the work happens.

Finish

Tool results return to the model until it reaches a final answer or the bounded loop ends.

Workspace confinement

File operations stay inside the configured workspace, with path traversal blocked before a tool runs.

BOUNDARY / SHELL

Allowlisted commands

Shell access is constrained to explicit commands instead of handing the model an unrestricted terminal.

BOUNDARY / LOOP

Finite execution

Each run has a maximum number of iterations, keeping a task from quietly becoming an endless process.

BOUNDARY / VIEW

Visible steps

The runner exposes the path to the answer, making tool use and intermediate results available for review.
