01 · What it is

Not an app you launch. A room inside the server.

It lives in the same Node process as the web backend. Press m and it switches the terminal into an alternate screen and draws a deck of boxed cards; press q and it hands the terminal back to the server logs — the music keeps playing. While the deck is up, every console.log is held to disk so the screen stays clean, and reported back on exit.

m enter 1–5 tabs Tab cycle card t theme b source i intensity u recovery q exit

02 · Now Playing

A real visualizer, not a fake one.

When VLC is driving and PipeWire capture is around, the deck taps the monitor sink and computes real spectrum bands; otherwise it falls back to synthetic bands and says so. Four meter styles, four intensity profiles, two themes — all cycled live from the keyboard.

bars

Classic partial-block level meters — read bass, mid, treble straight.

comet

A signal ribbon with an immediate head and a held peak marker.

split

Center-out spectrum, continuous filled bars with a soft dim trail.

spark

Low-noise text pulse with a held fleck — a lighter alternative to bars.

copper cream cyan mint lavender moon gold — classic copper · t cycles to aurora tide

03 · Static Chain

The operational face of an automated news pipeline.

The second tab is a live graph of the scrape → summarize → LLM → orchestrate → store chain. You can run a single node, a node plus its prerequisites, or the whole pipeline right from the terminal, and it waits and reports success, soft warnings, or failure.

04 · Cron · Logs · Situation

Three more tabs, all reading the same live backend.

3 · Cron

The schedule timeline — next fire, wait, lane markers, linked LLM task ids, and warnings. Expand a row for the raw job.

4 · Logs

Tails the day's server log; falls back to merged cron / scheduler / LLM-debug feeds. Scroll, page, jump to end.

5 · Situation

Signals, narratives, and correlations — score, status, category, evidence. Expand into a full Situation Report overlay.

u · Recovery

Overdue jobs, stale artifacts, an offline catch-up queue — start fresh, or recover chain A or B in place.

05 · One backend, two faces

The terminal deck and the admin map are the same machine.

Everything the deck shows — the pipeline, the cron lanes, the logs, the Situation feed — is the same backend the web admin drew as a System Map. One is the room you sit in; the other is the wiring diagram.

The Music Room

An in-process TUI. Music, pipeline, and intelligence in a deck of ANSI cards, driven entirely from the keyboard. This is where you work.

The System Map

The browser view of the same nodes — scheduler, cron, LLM routes, scraper, stores, builder — laid out as a graph you can read at a glance.

Anchored in March

It started in March and kept growing all spring.

The map came first; the room grew around it over the following months — the visualizer, the themes, the Situation feed. An ambitious local monolith that reached a long way.
