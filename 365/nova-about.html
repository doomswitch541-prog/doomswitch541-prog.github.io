The studio

A generation surface you fully own.

Nova is the same idea as the local chat, pointed at pixels: a focused browser page bridged to a diffusion backend running on the hardware already in the room. Choose the model, shape the prompt, and watch the image resolve — no account, no queue, no upload.

BACKEND / AGNOSTIC

One UI, either engine

Unified /api/nova/* endpoints speak to ComfyUI or AUTOMATIC1111 alike, auto-detecting which is online and translating sampler names across them.

MODELS / OFFLINE

Weights that stay put

Checkpoints pulled once from the official HuggingFace orgs drop into the backend and run offline forever — SD 1.5 and SDXL, no account needed to keep generating.

PROGRESS / LIVE

Watch it resolve

A WebSocket carries real-time step tracking from ComfyUI, with a polling fallback, so the denoise is visible instead of a spinner hiding the work.

IMAGES / PERSIST

Every frame is a file

Each generation saves a PNG beside a JSON of its settings and seed, filling a history filmstrip you can reopen, reproduce, or delete — the same pattern as the saved chats.
